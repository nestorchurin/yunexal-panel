# Snapshot - 24.05.2026 - 0.5.1

## chore(installer): OS snapshot version and dual version display

**OS version** (`/etc/os-release`) now follows the snapshot naming convention
(`26m05d24a`) instead of the semver panel release (`0.5.1`):

```
NAME="Yunexal Musl Panel"
VERSION="26m05d24a"
VERSION_ID="26m05d24a"
PRETTY_NAME="Yunexal Musl Panel 26m05d24a"
```

**Installer header** now shows both versions so the user knows exactly what
they are installing:

```
  Panel 0.5.1  ·  26m05d24a  ·  x86_64
```

- `Panel 0.5.1` — the Yunexal Musl Panel release version
- `26m05d24a` — the ISO/OS snapshot build identifier
