# Changes — 2026-05-28

### Added
- **feat(console):** command macro strip above the terminal with quick-run chips and a manage modal for per-server browser-stored commands.
- **feat(console):** command history recall with ArrowUp / ArrowDown and deduped persistence per server.
- **feat(console):** autocomplete dropdown that merges macros and recent history, so project-specific commands can be saved and recalled quickly.
