### Security hardening
- `src/auth.rs`:
	- `client_ip()` now trusts `X-Forwarded-For` / `X-Real-IP` only when the direct peer is a trusted local/private proxy address
	- mitigates spoofed client IP usage through direct untrusted requests
- `src/handlers/files.rs`:
	- `resolve_path()` now canonicalizes root and requested path/parent to enforce volume confinement across symlinks
	- blocks symlink-escape attempts outside server volume while preserving normal file operations
	- added tests for traversal and symlink-escape scenarios
- `src/handlers/admin.rs`:
	- self-update archive download now streams to disk with strict max size guard (128 MiB) and empty-download rejection
	- improved error cleanup for partial downloads
	- binary discovery in extracted archive now skips symlinks and enforces canonical path under extraction root
	- removed panic-prone unwrap in binary selection path
