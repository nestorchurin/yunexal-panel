# Changes — 2026-05-25b

### Added
- **feat(backups):** per-server Backups tab in the sidebar — lists all
  `.tar.gz` files from the container's `backups/` volume directory with
  filename, size, and creation timestamp; accessible via the sidebar link
  between Files and Networking.
- **feat(backups):** **Create Backup** button opens a modal to set a
  filename prefix; backup runs synchronously (button stays disabled and
  shows a spinner until the archive is complete); success toast shows the
  resulting filename and size.
- **feat(backups):** download button on each backup row (admin-only —
  hidden for regular users; backend enforces `is_admin_session` check).
- **feat(backups):** delete button with confirmation dialog on each row.
- **feat(backups):** backup count / limit badge next to the "Backups"
  heading (e.g. `3 / 10`); turns red when the limit is reached.
- **feat(backups):** **Max Backups** limit enforced server-side in
  `api_create_backup` — returns HTTP 422 with a human-readable error when
  the current count ≥ limit; Create button is disabled in the UI when at
  the limit.
- **feat(backups):** while a backup is in progress, a purple spinner
  banner appears at the top of the list and all download buttons are
  disabled with `pointer-events:none`.
- **feat(admin):** **Max Backups** field added to the Edit Server admin
  form; saved to `servers.max_backups` in SQLite (default 10).

### Fixed
- **fix(backups):** delete button `SyntaxError` — `JSON.stringify` inside
  an `onclick="..."` attribute injected raw double quotes that broke HTML
  parsing; fixed by wrapping with `escHtml()` to encode `"` as `&quot;`.
- **fix(backups):** Bootstrap modal `TypeError` on SPA navigation — modal
  HTML is no longer embedded in the page template; it is injected into
  `document.body` on demand via `_ensureModal()` so it survives SPA
  page-cache swaps.

### Performance
- **perf(scheduler):** `run_backup` blocking I/O (create dir, write
  archive, read dir entries) moved into `tokio::task::spawn_blocking` so
  the Tokio async executor is no longer blocked during archive creation.

### DB
- **migration:** `ALTER TABLE servers ADD COLUMN max_backups INTEGER NOT NULL DEFAULT 10`
