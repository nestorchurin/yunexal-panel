## Snapshot - 23.05.2026 - 0.5.1

### Alpine installer hardening: removed wireless and printer support

To reduce attack surface and keep installer behavior deterministic, support for
wireless networking and printer kernel modules is now disabled in the Alpine
installer flow and installed target.

- `scripts/iso/yunexal-installer.sh`:
  - networking step now explicitly runs in Ethernet-only mode
  - wireless interfaces (`wl*`, `wlan*`, `wwan*`) are rejected with a clear message
  - the installer menu loop now retries when networking validation fails

- `scripts/iso/genapkovl-yunexal.sh`:
  - added `/etc/modprobe.d/yunexal-disable-unsupported.conf` to live overlay
  - added the same modprobe policy to installed targets during `yunexal-install finalize`
  - disabled wireless stack modules: `cfg80211`, `mac80211`, `rfkill`
  - disabled printer modules: `lp`, `usblp`, `ppdev`, `parport`, `parport_pc`

Operational impact:
- installer and installed system now require wired Ethernet for network setup
- printer devices are not supported by default kernel module policy
